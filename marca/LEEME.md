# marca/

Aquí vive la identidad de **tu** marca. Esta carpeta empieza casi vacía: la llena el comando `/marca` a partir del cuestionario.

| Archivo | Qué guarda |
|---|---|
| `brand.json` | Nombre, contacto, colores, tipografías, logo y formatos (forma de ejemplo en `brand.ejemplo.json`) |
| `voz.md` | Quiénes son, tono, reglas, mensajes clave, llamadas a la acción y cómo cambia por red |
| `voz_personal.md` | Voz del dueño para sus perfiles personales (si aplica) |
| `nichos.md` | Cliente ideal y nichos, con su problema y su lenguaje |
| `objeciones.md` | Las dudas del cliente y cómo responderlas |
| `decisiones.md` | Lo que el dueño decidió y las contradicciones resueltas |
| `zernio.json` | Qué cuenta de Zernio corresponde a cada destino |
| `plantillas/lamina-4x5.css` | Diseño base de las láminas (`/marca` la adapta a tus colores) |
| `casos/PLANTILLA.md` | Plantilla para documentar casos reales con permiso del cliente |
| `logo.png`, `icono.png` | Los archivos del logo |
